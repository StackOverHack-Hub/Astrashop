# Measure the pilot

Compare the student’s usual method with Astrashop for one campus shop and a small set of exact course supplies. Use comparable items, urgency, and opening hours. If the same student tries both methods, use two comparable tasks so the first attempt does not change the stock or reveal the answer for the second. Vary which method goes first. Record recalled experiences separately from timed attempts.

| Metric | Baseline | Astrashop |
| --- | --- | --- |
| **Time to reliable confirmation** | Start when the student begins a call, message, or visit to check the item. Stop when the shop confirms the exact item can be picked up by the stated deadline. | Start when the student opens the catalog for the item. Stop when the student has a valid hold and the shop has verified that the exact unit is set aside for the stated pickup window. A stock badge alone does not end the timer. |
| **Pickups before the deadline** | Count attempts in which the student physically collects the exact item by the deadline set before the attempt. | Use the same deadline rule. Verify collection with the student or shopkeeper and cross-check the shop’s collected status where available. |

For every attempt, fix the deadline in advance. Record starts, verified confirmations, and pickups using the same time zone. Mark attempts without confirmation as **unconfirmed** and keep them in the attempt count. Report the median time for confirmed attempts together with the number confirmed. For on-time pickups, use **on-time pickups divided by all attempts**, including cancellations, misses, and failures. Count people separately from attempts.

Use the pickup pass’s **Set aside** time and the counter’s collection status to cross-check your notes. The counter’s **Pilot numbers** start timing at reservation and cover the app's reservation history. Use the attempt record below for catalog-open times, the baseline, and on-time pickup rates.
